
# 📦 KazPost Parcel Tracking

**Қазпошта сәлемдемелерін тіркеу және жеткізу мәртебесін бақылау жүйесі**

Бұл — Java және Spring Boot технологияларымен жасалған оқу жобасы. Жүйе сәлемдемелерді тіркеуге, трек-нөмір арқылы іздеуге және жеткізу мәртебесін бақылауға арналған.

## 🎯 Жобаның мақсаты

Қазпоштадағы сәлемдеме жеткізу үдерісін модельдеу және объектіге бағытталған бағдарламалау қағидаларын тәжірибеде қолдану.

## ✨ Негізгі мүмкіндіктер

- Сәлемдемелер тізімін көрсету
- Трек-нөмір арқылы іздеу
- Жіберуші мен алушы туралы ақпарат сақтау
- Жеткізу мәртебесін өзгерту
- Сәлемдеменің қозғалыс тарихын сақтау
- Стандартты және жедел жеткізу стратегиялары
- Gmail арқылы электрондық хабарландыру жіберуге арналған қызмет
- Автоматты құрастыру және тестілеу workflow-ы

## 🛠 Қолданылған технологиялар

- Java 17
- Spring Boot
- Spring Web
- Thymeleaf
- Maven
- HTML және CSS
- Java Collections: `Map`, `ArrayList`
- Jakarta Mail (Gmail SMTP)
- GitHub Actions

## 🧩 Жобалау үлгілері

| Үлгі | Қолданылуы |
|---|---|
| Factory | Сәлемдеме объектісін құру |
| Observer | Мәртебе өзгергенде хабарландыруды іске қосу |
| Strategy | Жеткізу түрі мен құнын есептеу тәсілін таңдау |

## 🚀 Жобаны іске қосу

Алдын ала компьютерде JDK 17 және Maven орнатылуы керек.

1. Репозиторийді жүктеп алыңыз:

```bash
git clone https://github.com/ajymaskar082/Kazpost-Parcel-Tracking.git
cd Kazpost-Parcel-Tracking
```

2. Жобаны іске қосыңыз:

```bash
mvn spring-boot:run
```

3. Браузерде ашыңыз:

```text
http://localhost:8080
```

## 📧 Gmail баптауы

Нақты хат жіберу үшін Gmail аккаунтында екі сатылы растауды қосып, App Password жасау және `GMAIL_USERNAME`, `GMAIL_APP_PASSWORD` орта айнымалыларын баптау қажет.

Құпиясөзді GitHub репозиторийіне немесе бастапқы кодқа жазбаңыз.
