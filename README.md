# 📦 Қазпошта сәлемдемелерін жеткізу және трекинг жүйесі

## 1. Жоба туралы

Бұл жоба Java бағдарламалау тілі негізінде Қазпошта сәлемдемелерін тіркеу, жеткізу және олардың қозғалысын бақылау жүйесінің оқу моделін әзірлеуге арналған.

Жүйенің негізгі мақсаты — сәлемдемелер туралы ақпаратты сақтау, трек-нөмір арқылы іздеу, жеткізу статусын өзгерту және статус тарихын бақылау.

**Жоба тақырыбы:** Сәлемдеме жеткізу және трекинг  
**Ұйым:** Қазпошта  
**Нұсқа:** 16  
**Бағдарламалау тілі:** Java  
**Java нұсқасы:** Java 17 немесе одан жоғары

## 2. Жобаның мақсаты

- Сәлемдемелерді тіркеу.
- Әр сәлемдемеге бірегей трек-нөмір беру.
- Жіберуші мен алушы туралы ақпаратты сақтау.
- Сәлемдемені трек-нөмір арқылы іздеу.
- Жеткізу статусын өзгерту.
- Статус өзгерістерінің тарихын жүргізу.
- Мәліметтерді CSV файлына сақтау және қайта жүктеу.

## 3. Зерттеу бағыты

Зерттеу барысында келесі мәселелер қарастырылады:

- Сәлемдеме түрлері.
- Трек-нөмірдің қызметі.
- Пошта бөлімшелерінің рөлі.
- Сәлемдеменің жеткізілу статустары.
- Сәлемдемені тіркеу және жеткізу бизнес-процесі.
- Қазпошта мен ұқсас трекинг жүйелерінің мүмкіндіктері.

Зерттеу материалдары `research.md` файлында берілген.

## 5. Негізгі кластар

| Класс | Қызметі |
|---|---|
| `Parcel` | Сәлемдеме туралы ақпаратты сақтайды |
| `Sender` | Жіберуші туралы мәліметтерді сақтайды |
| `Recipient` | Алушы туралы мәліметтерді сақтайды |
| `PostOffice` | Пошта бөлімшесі туралы ақпаратты сақтайды |
| `TrackingEvent` | Статус өзгерістерінің тарихын сақтайды |
| `DeliveryStatus` | Сәлемдеме статустарын анықтайды |
| `ParcelService` | Сәлемдемелерді тіркеу, іздеу және басқару қызметтерін орындайды |

## 6. Жеткізу статустары

Жүйеде келесі статустар қолданылады:

- `ACCEPTED` — сәлемдеме қабылданды.
- `IN_TRANSIT` — сәлемдеме жолда.
- `ARRIVED_AT_OFFICE` — сәлемдеме пошта бөлімшесіне келді.
- `DELIVERED` — сәлемдеме алушыға жеткізілді.
- `LOST` — сәлемдеме жоғалған деп белгіленді.

## 7. Жобаның негізгі талаптары

Бағдарламаны әзірлеу кезінде келесі талаптар ескеріледі:

- Объектіге бағытталған бағдарламалаудың төрт қағидасы: инкапсуляция, мұрагерлік, полиморфизм және абстракция.
- Кемінде 8 класс.
- Кемінде 1 интерфейс.
- Кемінде 1 абстрактілі класс.
- `ArrayList` және `HashMap` коллекцияларын қолдану.
- Қолданушы анықтайтын exception класын құру.
- Мәліметтерді CSV немесе JSON форматында сақтау.
- Java 17 немесе одан жоғары нұсқасын пайдалану.
- Консольдік мәзір арқылы жүйемен жұмыс істеу.

## 8. Жобаның шектеулері

Бұл — оқу мақсатындағы модель. Ол Қазпоштаның нақты ішкі ақпараттық жүйесіне қосылмайды және нақты сәлемдемелердің орналасқан жерін көрсетпейді. Жүйедегі мәліметтер демонстрациялық мақсатта қолданылады.

## 10. Қорытынды

Жоба сәлемдемелерді тіркеу, трек-нөмір арқылы іздеу, пошта бөлімшелерімен байланысты ақпаратты сақтау және жеткізу статустарын бақылау процестерін модельдеуге арналған. Жұмыс кезең-кезеңімен орындалады: зерттеу, UML диаграммаларын дайындау, Java бағдарламасын әзірлеу, тестілеу және қорғау.
