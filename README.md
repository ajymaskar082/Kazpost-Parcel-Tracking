# Сәлемдеме жеткізу және трекинг жүйесі

## 1. Жоба туралы

Бұл жоба Java бағдарламалау тілінде сәлемдемелерді тіркеуге, жіберуші мен алушы туралы ақпаратты сақтауға және сәлемдеменің жеткізілу мәртебесін бақылауға арналған.

Жоба «Қазпошта» ұйымының сәлемдеме жеткізу үдерісін оқу мақсатында модельдейді.

## 2. Жобаның мақсаты

Сәлемдемелерді басқару, трек-нөмір арқылы іздеу және жеткізу тарихын көрсету мүмкіндіктерін жүзеге асыру.

## 3. Негізгі функциялар

- Сәлемдемені тіркеу.
- Жіберуші туралы ақпаратты сақтау.
- Алушының байланыс деректері мен мекенжайын сақтау.
- Трек-нөмір арқылы сәлемдемені іздеу.
- Жеткізу статусын жаңарту.
- Сәлемдеменің қозғалыс тарихын көрсету.

## 4. Негізгі кластар

- `Parcel` — сәлемдеме туралы мәліметтер.
- `Sender` — жіберуші.
- `Recipient` — алушы.
- `PostOffice` — пошта бөлімшесі.
- `TrackingEvent` — жеткізу оқиғасы.
- `DeliveryStatus` — жеткізу мәртебелері.
- `ParcelService` — сәлемдемелерді басқару.
- `Main` — бағдарламаның негізгі класы.

## 5. Қолданылатын технологиялар

- Java
- Git
- GitHub

## 6. Жеткізу статустары

- ACCEPTED — сәлемдеме қабылданды.
- IN_TRANSIT — сәлемдеме жолда.
- AT_POST_OFFICE — пошта бөлімшесінде.
- DELIVERED — алушыға жеткізілді.

## 7. Күтілетін нәтиже

Пайдаланушы трек-нөмір арқылы сәлемдемені тауып, оның ағымдағы мәртебесін, алушы туралы ақпаратты және жеткізу тарихын көре алады.

Ескерту: бұл оқу жобасы, нақты «Қазпошта» ақпараттық жүйесіне қосылмаған.
